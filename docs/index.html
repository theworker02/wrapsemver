Overview

Wrap filesystem semver paths across POSIX and Windows conventions. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/wrapsemver.git
cd wrapsemver
node src/cli.js --help
node --test
