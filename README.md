# wrapsemver

Wrap filesystem semver paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/wrapsemver/

## Install / run

```bash
git clone https://github.com/theworker02/wrapsemver.git
cd wrapsemver
node src/cli.js
node --test
```
